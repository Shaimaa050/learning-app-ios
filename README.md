# Learning Journey App

Learning Journey App is an iOS application built using the MVVM (Model–View–ViewModel) architecture that helps you stay consistent with your learning goals. Choose a topic, set your goal duration, and track your daily progress. With freeze days and an activity calendar, build a learning habit that fits your routine.

## ✨ Features

- Set a learning topic and choose your goal duration.
- Log your daily learning activity.
- Use freeze days to take a break while maintaining your streak.
- Track learned and frozen days in a weekly overview.
- Browse your activity history in a monthly calendar.
- Edit your goal and start a new streak while keeping previous activity records.
- Save goals and activity records locally with SwiftData.
